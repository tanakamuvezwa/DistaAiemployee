# Dista AI Workspace Overview

Dista AI is a 100% local, zero-API desktop personal assistant built in Python.

## Core Features
1. **Interactive Pixel-Art Humanoid Avatar**:
   - 30FPS real-time canvas rendering with glowing orange highlights.
   - States: Idle, Listening, Thinking, Speaking.

2. **Offline Voice Engine**:
   - Speech-to-Text: Local microphone listener using SpeechRecognition.
   - Text-to-Speech: Offline `pyttsx3` voice synthesis.

3. **Integrated Local Tools**:
   - 📧 **Emails**: SQLite-backed local inbox & draft generator.
   - 📄 **Docs**: Local markdown/text file reader & summarizer.
   - 💬 **Messages**: Local chat & inbox manager.

## Security & Privacy
- Zero external API keys needed.
- Zero network traffic or cloud quota limits.
- 100% data privacy — everything stays on your machine.
