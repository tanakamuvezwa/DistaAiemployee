Connect Google Workspace

Enter your Google OAuth2 Client ID to connect your Gmail, Drive, Docs & Sheets.

Get yours free at Google Cloud Console → OAuth 2.0 Client IDs. Show setup guide ▸

  1. Go to console.cloud.google.com → select/create a project
  2. APIs & Services → Enable APIs → enable: Gmail API, Drive API, Docs API, Sheets API
  3. Credentials → Create Credentials → OAuth 2.0 Client ID
  4. Application type: Web application
  5. Add to Authorized JavaScript Origins
  6. Copy the Client ID and paste it above
⚠️ OAuth requires serving over HTTP(S), not file://. Use npx serve .
